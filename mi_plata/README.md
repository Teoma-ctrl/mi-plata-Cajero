# Sistema Bancario "Mi Plata"
Simulador bancario desarrollado en HTML5, CSS3 y JavaScript puro aplicando Programación Orientada a Objetos (POO), encapsulamiento, herencia y polimorfismo para la técnica laboral en Desarrollo de Software (CESDE).

## Instrucciones de Ejecución
1. Abre la carpeta del proyecto en **Visual Studio Code**.
2. Asegúrate de tener instalada la extensión **Live Server** en VS Code.
3. Haz clic derecho sobre el archivo `index.html` y selecciona **"Open with Live Server"**.
4. La aplicación se abrirá automáticamente en tu navegador web predeterminado.
